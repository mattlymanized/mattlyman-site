# mattlyman-site

Source for mattlyman.com (GitHub Pages).

- `index.html`, `robots.txt`, `sitemap.xml`, `llms.txt`, `favicon.svg`, `CNAME`: the generated site. Do not hand-edit; change `tools/build_site.py` and re-run `python3 tools/build_site.py`.
- `images/`: compressed web images (metadata stripped).
- `Matt_Lyman_Resume.pdf`: public resume (no phone, no email).
- `docs/talks-and-podcasts.md`: episode list with summaries. Public, and disallowed in robots.txt.
